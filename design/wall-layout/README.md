# Wall Layout

`active-field.svg` is the measured Phase 2 layout canvas. It is not a final engineering drawing.

The SVG uses inches as its coordinate system: `0,0` is the top-left of the `90 in x 80 in` active field, and `90,80` is the lower-right of that field.

Use it to mark the active field, no-go zones, trigger column, gong court, depth bands, and mechanism neighborhoods as they emerge. Nearby overflow annotations describe wall constraints around the active field; they are warning context, not normal build space.
