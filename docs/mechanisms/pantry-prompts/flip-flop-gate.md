# Flip-Flop Gate Prompt Brief

Source: [Mechanism Pantry](../pantry.md)

Clarity: `clarity: expanded`, `clarity: needs-storyboard`

Suggested art format: `art: three-frame storyboard`

## Purpose

Alternate successive balls between two exits using a bistable gate.

## Subject Brief

Show a Y-shaped marble path with a small seesaw gate at the fork. The gate has two stable resting positions: tipped left or tipped right. It is not centered.

Frame 1: the gate is tipped left, blocking or deflecting the next ball into the right exit. Frame 2: the ball passes and bumps the gate over to the right. Frame 3: the next ball is now deflected into the left exit and bumps the gate back.

The gate should look like a small mechanical memory bit: its current physical position determines the next route, and each passing ball changes that state.

## Must Show

- Y-shaped entry and two exits.
- Gate pivot.
- Two stable gate positions.
- Ball changing the gate state as it passes.

## Avoid

- A loose flap with no stable positions.
- A splitter that sends both balls the same way.
- A gate that requires hidden electronics.

## Open Questions

- What detent or over-center geometry makes the two states stable?
- Does this help the meal machine, or is it mostly useful for repeated test cycles?
- Can it be reset manually to a known starting state?
