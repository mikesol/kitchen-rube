# Falling Domino Decoder Prompt Brief

Source: [Mechanism Pantry](../pantry.md)

Clarity: `clarity: needs-rewrite`, `clarity: needs-storyboard`

Suggested art format: `art: three-frame storyboard`

## Purpose

Route different input positions into different falling subchains, then optionally rejoin them at one downstream release.

## Subject Brief

This brief is still mechanically unresolved.

The intended picture is a decoder face where an incoming selector or ball starts one of several small domino subchains. Each subchain represents a different meal or route condition. The subchains may take different physical paths, trigger different intermediate mechanisms, then converge on a shared latch or output.

For a first visual, show three input positions on the left, three short falling-tab subchains in the middle, and a shared output latch on the right. The key question is how to prevent the wrong subchains from firing.

## Must Show

- Multiple possible input positions.
- Separate subchains, not one generic row.
- Some physical reason only one subchain starts.
- A possible convergence point or shared output.

## Avoid

- A decorative branching pattern with no selective start.
- All subchains falling at once.
- Hidden logic that decides the route.

## Open Questions

- What physically selects one subchain?
- Should subchains rejoin or stay separate?
- Is this better described as a sorter, decoder, or switchyard?
