# Pantry Prompt Briefs

These files preserve the prompt-level understanding behind pantry mechanisms that may need concept art.

They are not final image prompts, CAD specs, dossiers, or build commitments. They are detailed subject briefs: enough physical picture, starting state, motion sequence, and output that a future reader can ask useful questions before any generated image exists.

Use these briefs when a pantry entry has an `art:` tag or when the one-line mechanism entry is not yet grokable.

## Brief Format

Each brief should include:

- Source pantry entry.
- Clarity status.
- Suggested art format.
- Mechanism purpose.
- Detailed subject brief.
- Must-show mechanical facts.
- Avoid list.
- Open questions.

If a brief exposes that the mechanism is still fuzzy, keep the brief and mark the uncertainty. The point is to make uncertainty inspectable, not to overdesign the part.
