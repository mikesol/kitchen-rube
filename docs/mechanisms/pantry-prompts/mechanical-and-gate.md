# Mechanical AND Gate Prompt Brief

Source: [Mechanism Pantry](../pantry.md)

Clarity: `clarity: expanded`, `clarity: needs-storyboard`

Suggested art format: `art: three-frame storyboard`

## Purpose

Require two physical conditions before an output latch can move.

## Subject Brief

Show an output latch or small gate blocked by two separate mechanical blockers. One blocker is removed by the meal selector. The other blocker is removed by a route ball, falling tab, or lever. Only when both blockers are gone can the output latch slide or rotate.

Frame 1: both blockers are in place; output cannot move. Frame 2: selector removes blocker one, but output is still blocked. Frame 3: route signal removes blocker two, and the output latch opens.

The concept should read as physical logic, not electronics: two real pieces must be moved out of the way.

## Must Show

- Output latch or gate.
- Two independent blockers.
- Selector removing one blocker.
- Route event removing the other blocker.
- Output still blocked if only one condition is met.

## Avoid

- Abstract circuit-gate symbols.
- A single latch that looks like it could open after one signal.
- Hidden logic inside a box.

## Open Questions

- Are the blockers pins, sliding bars, hooks, or rotating catches?
- Does order matter, or can either input arrive first?
- What resets both blockers to safe state?
