# Mechanism Index

This is not a fixed bill of materials. It is a live map of possible mechanisms, dreams, sketches, PoCs, integrated assemblies, retired ideas, and pantry shelves.

## Phase 3 Mechanism Pantry

Phase 3 is a maximum-breadth pantry-stocking pass.

- [Mechanism Pantry](pantry.md)
- Design: [Phase 3 Mechanism Language Design](../plans/2026-05-14-phase-3-mechanism-language-design.md)

Full dossier promotion is deferred until the end of Phase 3. A strong idea can be marked as a promotion candidate later, but most pantry entries should remain raw ingredients.

## Dossier Promotion Boundary

Create a new full dossier only when a mechanism becomes important enough to compare, test, reserve wall real estate, or reason about safety and reset in detail.

Phase 3 should defer that choice until the pantry has been stocked and reviewed.
